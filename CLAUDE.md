# Claude Session Manager

Native SwiftUI macOS app (SPM, macOS 15+). See README.md for what it does and how it works.

- Build the app with `./build.sh`; run tests with `swift test`.
- Keep `ClaudeSessionCore` free of SwiftUI/AppKit; UI lives in `Sources/ClaudeSessionManager`.

## Keep README.md current

Whenever a change affects anything README.md describes — features, menu or window behaviour, keyboard shortcuts, statuses and their copy, notification rules, files read or written, paths or env vars, the plugin, build/test commands, requirements, or the project layout — update README.md in the same commit.
